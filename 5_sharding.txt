Sharding and Partitioning

Sharding : method of distributing data across multiple machines (About Database)

Partitioning : splitting a subset of data within the same instance (About Data)

Each DB server is thus a shard and we say that the data is partitioned

Overall a database is sharded while the data is partitioned

there are two categories of Partitioning

1.horizontal Partitioning
2.Vertical Partitioning
